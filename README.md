# Anthony's Graduation Invitation

A dependency-free static invitation site ready for GitHub Pages.

## Publish

1. Create a GitHub repository and add these files.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## RSVP database

The RSVP form submits with Vanilla JavaScript AJAX to Formspree form `xykapwdp`.
Responses appear in the connected Formspree dashboard and guests remain on the
invitation after submitting.
